- Default local workspace for future GitHub repo checkouts: `/Users/wujinan/Documents`.
- If the user says to clone a repo and does not specify a path, place it under `/Users/wujinan/Documents/<repo-name>`.
- For the user's `意見調查表` family, prefer the branch the user asked for; if they say "dev", treat it as the repo's `develop` branch and switch/create tracking there.
