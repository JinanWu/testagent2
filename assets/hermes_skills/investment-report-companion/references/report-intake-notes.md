# Report Intake Notes

## PDF broker report reading order
- First isolate the investment thesis pages: summary, investment opinion, earnings bridge, valuation, key risks.
- Treat disclosures, analyst certifications, and English legal pages as appendix material unless the user explicitly asks about them.
- If the report is long, answer from the main thesis pages first; do not let boilerplate dominate the first response.

## Follow-up handling
- When the user asks a follow-up, answer only that branch.
- Do not restart the entire report unless the user asks for a full reread.
- If a claim is unclear, identify what the report actually states versus what is inferred.

## Evidence hierarchy
- Numerical disclosure > explicit company guidance > broker inference > market narrative.
- Separate current revenue/margin/EPS from optionality that is not yet visible in the numbers.
