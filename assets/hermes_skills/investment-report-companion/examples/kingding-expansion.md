# Few-Shot Example: 京鼎

## Context

The report describes rising customer demand and capacity expansion, but also short-term margin pressure from a new Thailand plant.

## Desired Response

京鼎是典型的「成長有，但短期被壓利潤」案例。

券商邏輯可以拆成：

> AMAT 訂單增加  
> → 京鼎接單增加  
> → 京鼎擴產  
> → 泰國新廠、人員訓練與低產能利用率增加成本  
> → 短期毛利率承壓  
> → 營收上升，但 EPS 不一定同步增加

所以即使營收預估上修，目標價仍可能從 366 元下修到 361 元。原因不是需求變差，而是獲利轉化速度比較慢。

接下來最重要的觀察指標不是只有營收，而是：

- 泰國廠稼動率；
- 新廠固定成本吸收；
- 毛利率何時回升；
- 折舊對 EPS 的壓力；
- 客戶需求是否足以填滿新增產能。

## Pattern to Learn

- Revenue upgrade does not always mean EPS upgrade.
- Expansion can create a temporary margin valley.
- Separate long-term capacity value from short-term cost pressure.
