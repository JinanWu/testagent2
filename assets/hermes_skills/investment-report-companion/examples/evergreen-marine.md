# Few-Shot Example: 長榮航運

## Context

The report discusses freight-rate changes, Red Sea detours, supply-demand dynamics, dividends, BVPS, and PBR-based valuation.

## Desired First Response

長榮不能只用一般成長股的方式看。它本質上是高度循環股，獲利核心不是單純營收成長，而是運價與有效供給的變化。

最基本的商業模型是：

> 營收 = 貨量 × 平均運價

> 毛利 = 貨量 × 平均運價 − 船舶成本 − 燃油成本 − 港口與營運成本

紅海繞道的重要性，在於它讓相同船隊需要航行更久，等於短期壓低有效供給。即使名目船舶數量沒有下降，市場能使用的運力仍然變少，因此運價容易上升。

但航運股最大的陷阱是：高峰期 EPS 很高，所以 PER 看起來很低。這不一定代表便宜。真正要看的是運價能維持多久、新船交付會不會重新壓低供給緊張，以及 PBR、股利與現金部位是否提供下檔保護。

## User Follow-Up

> 為什麼用 PBR，不是 PER？

## Desired Follow-Up Response

因為航運 EPS 波動太大。景氣高峰時 EPS 會被運價放大，PER 看起來非常低，但這可能只是高峰獲利造成的假便宜。

PBR 比較適合回答另一個問題：市場現在願意用多少折價買進公司的淨資產與現金部位。

但 PBR 也不是萬能。還要一起看：

- BVPS 是否穩定；
- ROE 是否能維持；
- 股利是否提供保護；
- 目前運價是高峰、正常化，還是新一輪上升；
- 紅海事件屬於短期擾動，還是會長期壓低有效供給。

## User Follow-Up

> 這個成長是真的嗎？

## Desired Follow-Up Response

需要拆開看。

若 EPS 上升來自現貨運價與短期地緣政治擾動，這是循環性改善，不是穩定複利成長。

若獲利增加來自金融資產評價利益、匯兌或其他業外，則更不能當成核心本業改善。

因此，判斷長榮時要分成：

1. 已實現獲利：目前已認列的運價與貨量。
2. 未來 optionality：旺季運價、紅海繞道持續時間、長約重談、供需缺口。
3. 下檔保護：PBR、現金、股利。

## Pattern to Learn

- Classify as cyclical before valuing.
- Use effective supply, not only nominal capacity.
- Separate core freight earnings from non-operating items.
- Do not treat low PER as proof of cheapness.
