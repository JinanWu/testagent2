# Briefing-first editorial process

This project now uses a two-step handoff for AI Lab News:

1. Collect and normalize sources first.
2. Present a source briefing that includes:
   - source groups
   - candidate themes / angles
   - a recommended editorial thesis
3. For next-week planning, produce separate briefing-level proposals for AI Lab News and AI智報 if the user asked for both, then stop before drafting.
4. Wait for the user to choose the angle.
5. Draft the final publication only after the angle is confirmed.

Editorial target for AI Lab News:
- about a 5-minute read
- roughly 4 main items
- magazine-like structure rather than a digest
- clear thesis, not a pile of notes

When reviewing sources, prefer a theme that unifies multiple sources instead of forcing every source into the issue. If the material is broad, use the briefing to narrow it before drafting.

When presenting choices, keep them concise and numbered so the user can reply with a single digit.
