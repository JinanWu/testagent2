# AI智報 Weekly Writing

## Overview

AI智報 is a weekly AI application digest for non-IT departments. It should translate the week's AI changes into practical, plain-language guidance.

## When to Use

Use this skill when:

- Producing an AI智報 weekly draft.
- Reviewing a weekly draft for readability and usefulness.
- Turning daily AI Lab News materials into a general-audience digest.

## Audience

Primary audience: colleagues outside the IT / information department.

They care about:

- What changed this week.
- Why it matters in normal work.
- Which tools or methods are useful.
- How to try something today.

6. 推薦模板 / 提示詞
7. 延伸閱讀

## Writing Rules

- Use plain language.
- Minimize jargon.
- Convert technical updates into work implications.
- Prefer practical examples.
- Include source links.
- Derive from the week's daily materials when possible.
- Do not include a `導入可能性` field.

## Review Checklist

- [ ] General colleagues can understand it.
- [ ] Has practical tools, cases, tips, or prompts.
- [ ] Links back to sources.
- [ ] Does not simply copy daily entries.
- [ ] No `導入可能性` field.
