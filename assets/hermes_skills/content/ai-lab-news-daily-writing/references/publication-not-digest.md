# Publication-not-digest pattern

Use this when the user says a draft feels like a directory, outline, or source index instead of a publishable article.

## What to change
- Move from item listing to thesis-driven narrative.
- Open with the editorial claim, not a source roster.
- Group sources by the story they support.
- Add why-it-matters reasoning after each item or section.
- End with a synthesis or recommendation.

## What to avoid
- A table-of-contents feel.
- Long lists of source names without interpretation.
- Too many bullets that merely restate headlines.
- Metadata-like fields in the main body.

## Practical rewrite recipe
1. State the core angle in one sentence.
2. Add 2-4 body sections that each explain a distinct implication.
3. For each section, include context, interpretation, and impact.
4. Close with a concise judgment for the target audience.
