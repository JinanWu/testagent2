# Website-informed reminders

When the user asks for a reminder based on a website, create a concise body that is usable later without re-reading the whole page.

Recommended body shape:
- 來源: URL
- 先看重點: 3–7 bullets
- If relevant, include:
  - key dates / deadlines
  - required forms or steps
  - eligibility / participation constraints
  - document/page limits
  - data/privacy/authorization caveats
  - contact / follow-up info

Good style:
- Keep only actionable facts.
- Prefer short bullets over paragraphs.
- Preserve exact dates, times, counts, and thresholds.
- If the site is a competition or application flow, mention the next concrete action the user should take.

Verification:
- After writing the reminder, read it back or inspect the reminder properties to confirm the body and due date were stored correctly.
