# Project Backlog Reminder Template

Use this template when a user wants a complex project decomposed into Apple Reminders items.

Recommended reminder structure:

Title:
- Short action-oriented task name

Body:
- 任務背景: why this task matters and what problem it solves
- 要執行的內容: concrete steps the user or agent should perform
- 預期產出: the expected artifact/result
- 驗收標準: how to tell the task is complete

Guidelines:
- Keep each reminder atomic and executable in a short session.
- Prefer 8-15 reminders for a medium project; split further if any item still contains multiple phases.
- Use fixed wording for the four body sections so items remain scannable.
- If the user already defined a scope, preserve it verbatim in the body rather than paraphrasing it away.
- For daily or recurring operational projects, add history/traceability requirements explicitly in the acceptance criteria.
- After writing the list, verify the reminder count and inspect a few names to confirm creation succeeded.
