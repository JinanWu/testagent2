# System intake map

- Start by mapping stable nouns: repos, entrypoints, environments, tables, schedulers, consumers, dependencies.
- Build the map in layers: product goal, repo roles, runtime flow, environments, data stores, triggers, risks.
- Verify names and roles with repo docs and live CLI output.
- Keep dev/prod drift explicit instead of collapsing environments.
- Treat the chat surface as an entry channel, not the platform itself.
