# Codex pre-flight checklist

Use this before launching Codex on a coding task.

- Confirm the target repository path.
- Confirm the exact change request.
- Confirm constraints: branch target, files to avoid, test scope, style conventions.
- Verify the repo is a Git checkout.
- Verify Codex CLI is available and authenticated.
- Write a single, tight prompt that includes the objective and validation steps.
- Prefer one repo/task per Codex run unless the task is intentionally batchable.
- If the user only asked about capability, do not start Codex yet.
