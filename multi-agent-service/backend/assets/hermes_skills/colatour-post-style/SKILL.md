# 可樂旅遊 FB 貼文風格

依此規範撰寫或改寫貼文。**先套版型，再調語氣，最後檢查禁用清單。**

## 何時使用

- 要寫一則新的粉專貼文（景點、節慶、行程、郵輪、機票、懶人包）
- 手上有一段行程說明或新聞稿，要改寫成貼文
- 同仁寫好草稿，說「幫我修成粉專的語氣」
- 提到「可樂旅遊風格」「我們粉專的調性」

---

## 動筆前：素材夠不夠？

**素材夠 → 直接輸出成品，不問。素材不夠 → 先問，一次問完。**

素材夠的判準是這三件事都成立：

1. 看得出**貼文類型**（景點推薦／節慶預告／行程開賣／知識懶人包／產品優惠）
2. 有**具體主體**（可寫成條列的景點、亮點或活動，至少 2 項）
3. 知道**這則要達成什麼**（讓人收藏？記住日期？點連結？）

有一項不成立就先問。

### 怎麼問

**一次問完，最多兩題，給選項。** 不要一題一題來回，也不要開放式問「你想怎麼寫」—— 同仁多半沒想過，給選項他才選得下去。

> 使用者：寫一篇四月適合東京賞櫻
>
> 先確認兩件事再動筆：
>
> 1. 這則想走哪個方向？
>    ・**景點推薦** —— 列 3–5 個賞櫻名所，附交通與花期
>    ・**知識懶人包** —— 講花期怎麼抓、怎麼避開人潮，收藏取向
>    ・**行程開賣** —— 帶特定團體行程與連結
>    ・**互動徵集** —— 「一人說一個」邀留言，走輕鬆路線
> 2. 有指定的行程連結或主打團嗎？沒有的話我就寫成不帶連結的收藏型貼文。

問完就寫，**不要再確認第二輪**。使用者只回了第 1 題就照第 2 題的預設值走。

### 這些不要問

| 情況 | 做法 |
|---|---|
| 缺日期、票價、優惠金額 | 不問，文內標 `花期｜待確認`，最後一行提醒補齊 |
| 缺連結 | 不問，寫成收藏型 CTA，不放 `👉` 那行 |
| 不確定鉤子用哪種 | 不問，自己選（第 3 節），使用者覺得不對會直接說「換一種」 |
| 不確定條列用 emoji 還是編號 | 不問，用「讀者要挑一個還是都收下」判斷（第 4 節） |
| 不確定符號、行長、CTA 寫法 | 不問，照規範選 |

**只問「決定這則長什麼樣」的事，其餘自己決定。** 問太多會變成問卷，同仁下次就不用了。

### 輸出方式

直接輸出完整貼文，**可以整段複製貼上**。不要加「以下是為您撰寫的貼文」這類前後綴，也不要解釋你用了哪個鉤子。

只有兩種情況在貼文**後面**用一行補充：

1. 文內有 `｜待確認` → 提醒補齊
2. 有事實被你降級處理（例如原稿「現折 5000 元」改成「早鳥優惠」）→ 說明為什麼


## 1. 核心語氣

| 特徵 | 說明 |
|---|---|
| 溫柔知性、像懂很多的朋友 | 不吆喝、不叫賣，用「值得看一眼」的語氣邀請 |
| 畫面感優先 | 具體描寫勝過形容詞堆疊：「熊熊火焰沿著繩索從 70 公尺高的斷崖落下」＞「超級震撼」 |
| 資訊密度高 | 每則都給得出實用資訊（日期、景點名、交通、亮點），不寫空話 |
| 促銷克制 | 優惠一句話帶過，放在最後，不重複強調 |
| 第二人稱「你」 | 對著一個人說話，不用「各位」「大家」；品牌自稱「我們」，絕不自稱「小編」 |

判斷一句話合不合格的最快方法：**把它讀出來，如果像在喊麥就重寫，像在跟朋友介紹就留著。**

## 2. 版型

```
{鉤子}                    ← 1–2 行，決定讀者要不要按「顯示更多」

{轉場句}                  ← 1 行，把鉤子接到主題（互動式鉤子跳過）

【{活動或系列名}】
活動期間｜{日期}

{emoji} {名稱}｜{一句話說明}
{emoji} {名稱}｜{一句話說明}
{emoji} {名稱}｜{一句話說明}

{收束句}                  ← 1 行，把上面的點收成一個概念

{CTA}
👉 {連結}

分享世界的美好★ #可樂旅遊 #{國家} #{目的地} #{主題}
```

**這是預設版型，多數貼文都長這樣** —— 條列用 emoji 行首，景點、亮點、體驗、客層分眾都適用。

只有一種情況把 emoji 行首換成資訊符號：**同一則要並列比較幾個方案**（不同行程、不同天數、不同艙等房型），或步驟有明確先後順序。讀者得橫向對照著看，數字才幫得上忙：

```
▌{區塊小標}
❶{名稱}｜{一句話說明}
❷{名稱}｜{一句話說明}
❸{名稱}｜{一句話說明}
```

**只是分類列舉就別編號** —— 楓葉／溫泉／美食各一項不是方案，讀者不用從中挑一個，用圖示比用數字好認。

規則：

- 鉤子必須在前兩行講完（FB 折疊線大約在第 3 行）
- 簽名行 `分享世界的美好★` 固定放最後，前面空一行；結尾 hashtag 接在**同一行**後面
- 沒有活動名、沒有日期的貼文，直接跳過那兩行，不要硬湊
- **換掉的只有條列前綴** —— `【】` `活動期間｜` `｜` `×` `👉` `★` 兩種條列通用，`▌` 是區塊小標不是條列前綴，emoji 條列照樣可以用它分區塊

## 3. 鉤子寫法

五選一，選完就往下寫，不要在開頭堆兩種。

| 類型 | 適用 | 範例 |
|---|---|---|
| **提問式** | 景點推薦、懶人包 | `不想每次來韓國都只去首爾、釜山嗎？` |
| **畫面式** | 節慶、特殊體驗 | `入夜之後，上萬盞燈籠會從南江上游一路漂下來。` |
| **反常識式** | 冷門目的地、知識型 | `挪威最值得待的季節，其實不是夏天。` |
| **時間式** | 節慶預告、限期活動 | `一年只點亮十六天。` |
| **互動式** | 主題徵集、輕鬆話題、想衝留言數 | `一人說一個你認為佐賀秋天必去的行程！`／`我先來😍` |

**互動式的特別規則**：邀請留言之後要**自己先示範**（「我先來」），下面接的清單就是你的答案。這種鉤子**不接轉場句**，直接進清單 —— 中間再插一句轉場會把對話感切斷。

**轉場句**接在鉤子後面，把讀者從鉤子帶進主題，一行講完：

```
不想每次來韓國都只去首爾、釜山嗎？
推薦收藏這兩座韓國寶藏城市
```

鉤子禁止直接寫成標題（`【2026晉州南江流燈節】開賣`）—— 那是公告不是貼文。

## 4. 符號、Emoji 與 Hashtag

| 符號 | 用途 | 範例 |
|---|---|---|
| `｜` 標籤行 | 日期、期間、場次 | `活動期間｜2026/7/24－11/29` |
| `❶❷❸❹❺` | 並列比較的方案，或有先後順序的步驟 | `❶5天・破冰船｜行程最短` |
| `▌` | 區塊小標 | `▌節慶亮點` |
| `↪︎ ⋯ ↩︎` | 補充清單的引導 | `↪︎更多值得收藏的紅葉景點在這裡 ↩︎` |
| `👉` | 指向連結，**有網址就一定要有** | `👉 https://colatour.tw/xxxx` |
| `｜` | 全形分隔「名稱｜說明」 | `統營｜海景城市 × 玩樂一次滿足` |
| `×` | 兩個概念並置 | `晉州 × 統營`、`歷史古城 × 浪漫燈海` |
| `【】` | 活動、專題、系列名 | `【2026晉州南江流燈節】` |
| `★` | 只出現在簽名行 | `分享世界的美好★` |

### 連結寫法

**貼文裡出現網址，前面一律加 `👉`**，連結獨立成行、`👉` 後面空一格：

```
↪︎更多秋季韓國行程在這裡 ↩︎
👉 https://colatour.tw/xxxx
```

不要用 `⮕`、`>`、`→` 或裸貼網址 —— 連結行只有 `👉` 一種寫法。`👉` 是連結標記不是裝飾，所以那行不再放別的 emoji，也不要 `👉👉`。

### 日期寫法

有日期就寫成 `{標籤}｜{日期}` **獨立成行**，接在 `【】` 標題下面：

```
【2026晉州南江流燈節】
活動期間｜2026/10/3－10/18
```

- 標籤照內容選：`活動期間`、`展期`、`花期`、`開賣日期`、`出發日期`、`航程期間`
- 年份寫在最前面一次，結束日同年不重複年份：`2026/7/24－11/29`
- 跨年度兩邊都寫完整：`2026/12/20－2027/1/5`
- 月日不補零 —— 寫 `7/24`，不寫 `07/24`
- 連接號用全形 `－`，不要用半形 `-`、`~` 或「至」
- 單日活動只寫一個日期：`活動日期｜2026/8/15`
- 日期沒查證到：`活動期間｜待確認`，文末提醒同仁補齊（第 8 節）

同一則裡可以有兩行標籤（例如 `活動期間` 加 `開賣日期`），但不要超過兩行 —— 再多就是型錄不是貼文。

### 條列符號：預設 emoji，方案並列才編號

| 系統 | 長相 | 用在 |
|---|---|---|
| **Emoji 行首型（預設）** | `🍁` `♨️` `🍲` 各起一行 | 分類列舉：景點、亮點、體驗、客層分眾。讀者是「一路看下來」，不是從中挑一個 |
| **編號型** | `▌區塊小標` + `❶❷❸` | 並列比較的方案（不同行程／天數／艙等房型），或有先後順序的步驟。讀者要橫向對照 |

判斷法：**這幾項是要讀者「挑一個」還是「都收下」。** 挑一個用編號，都收下用 emoji。

**不混用的是「條列前綴」**：用了 🍁♨️🍲 就整段用完，不要中途冒出 ❸。

其他符號**不受條列系統限制**，該用就用。emoji 行首搭 `｜說明`、搭 `【】` 標題、搭 `👉` 連結都是正常寫法：

```
【MSC榮耀號｜2027春夏航程】
開放預訂｜2027 春夏航程

👨‍👩‍👧‍👦 帶長輩與小孩的家庭｜免去舟車勞頓與搬行李的麻煩，船上各年齡層都能找到自在的步調
🧳 不想做功課的度假族｜吃住與娛樂全包在船上，睡醒就輕鬆抵達下一個目的地
```

客層分眾是分類列舉不是方案比較，所以用 emoji 行首。**行首 emoji 後面空一格**再接名稱。

超過 5 項的清單不要編號 —— 改用 `▌` 分區塊，或拆成兩則貼文。

### Emoji 用法

**emoji 沒有被禁用**，但有一條硬規則：**一行最多一個 emoji。**

不管是不是同一個、不管放在行首還是句尾，一行就是一個。`🔥🔥` 不行，`🍁♨️` 也不行，`🍁漫步楓紅秘境😍` 更不行 —— 後兩者雖然 emoji 不同，一樣算兩個。

在這條前提下，只有三個位置能放：

1. **行首分類符** —— 必須跟該行內容對得上：楓葉配 🍁、溫泉配 ♨️、美食配 🍲、陶藝配 🏺、圖書館配 📚。對不上就別放。放了行首分類符，那行**句尾就不能再放語氣 emoji**。
2. **語氣 emoji** —— 只出現在互動式鉤子或收束句，**一則最多兩個**（分散在不同行），例：`我先來😍`、`都能一次滿足🍂`。
3. **連結行的 `👉`** —— 有網址就一定要放，且那行只有它一個 emoji。它不算進「語氣 emoji 一則兩個」的額度。

其餘位置一律不放。禁止：一行放兩個以上（含不同 emoji）、疊放（😍😍、🎉🎉🎉）、句尾隨手灑、拿 emoji 當標點用。

**怎麼算「一個」**：以螢幕上顯示成幾個圖示為準，不是拆成幾個字元。ZWJ 組合字（👨‍👩‍👧‍👦 家庭、👩‍💻、🏳️‍🌈）顯示成一個圖示就算**一個**，可以當行首分類符。`😍😍`、`🍁♨️` 都是兩個圖示，都超標。

一行需要兩個 emoji 才講得完，通常是那行塞了兩件事 —— 拆成兩行，各配一個。

判準一句話：**emoji 是在幫讀者分類或定調，不是在裝飾。** 拿掉之後那行如果照樣讀得懂、只是變樸素，就是裝飾，刪掉。

### Hashtag

兩種用法，可以同時出現：

| 位置 | 寫法 | 說明 |
|---|---|---|
| **句中** | `#環境藝術之森 滿滿日系秋意` | 把景點、店名、專有名詞直接標成 tag，讀起來仍是句子的一部分；一行最多 2 個 |
| **結尾** | `分享世界的美好★ #可樂旅遊 #日本旅遊 #佐賀 #佐賀景點` | **接在簽名行同一行後面**，不另起一行 |

結尾 tag 組成固定順序：`#可樂旅遊` → 國家或地區 → 目的地 → 主題，**共 3–6 個**。

不要用長句當 tag（`#佐賀秋天必去的景點`），也不要重複同義 tag（`#佐賀` `#佐賀旅遊` `#佐賀自由行` 三個並列只留一個）。

## 5. 條列寫法

**兩種條列系統都適用。** 前綴換了，寫法不變。

條列一律「**名稱｜一句話說明**」，講清楚「能看到什麼／能做什麼」，不用形容詞收尾。互動型貼文（第 11 節）可以把說明寫得更口語、更短。

說明長度看項目數 —— **條列是主體就寫長，條列是清單就寫短**：

| 項目數 | 說明長度 | 情境 |
|---|---|---|
| 2–3 項 | 25–35 字 | 條列本身就是貼文主體，每項要說服人（客層分眾、船上設施、行程差異） |
| 4–5 項 | 15–25 字 | 標準景點清單 |
| 6 項以上 | 10–15 字 | 純列名，或改拆成兩則 |

```
✓ 閑麗水道觀景纜車｜登上彌勒山，眺望壯闊多島海景
✓ 東皮郎壁畫村｜沿著坡道走，轉角都是面海的彩繪牆
✓ 中央傳統市場｜現點現吃的忠武飯捲與海鮮，當地人的日常
```

```
✗ 閑麗水道觀景纜車｜超級無敵美，一定要去！        ← 形容詞，沒給資訊
✗ 東皮郎壁畫村｜壁畫村                            ← 說明等於重複名稱
✗ 中央傳統市場｜統營市中心最具代表性的傳統市場之一，
  匯集各式海鮮與在地小吃，是體驗當地生活的最佳去處  ← 太長，超過兩行
```

**名稱用正式全名**（第一次出現時），別用簡稱或暱稱。

## 6. CTA

一則只放一個，放在收束句之後、簽名行之前。**不要疊兩種。**

| 貼文類型 | CTA 寫法 |
|---|---|
| 景點推薦 | `↪︎更多{目的地}行程在這裡 ↩︎` + `👉 連結` |
| 節慶預告 | `想在現場看一次的，日期先記下來` |
| 知識懶人包 | `先收藏起來，出發前再翻一次` |
| 行程開賣 | `開賣日期｜{日期}` + `👉 連結` |
| 產品優惠 | 一句話帶過，例：`早鳥優惠同步開跑，名額有限` + `👉 連結` |

優惠**只講一次**。開頭講過就不要在 CTA 再講，CTA 講了就不要在中間鋪陳。

---

## 7. 行長與排版

- 段落之間空一行，**每段不超過 3 行**
- 單行超過 25 字就斷行，斷在語意停頓處，不要斷在詞中間
- 一則貼文控制在 **150–350 字**；超過就砍掉重複的亮點，不要壓縮說明
- 句號**只在段落結尾用**，條列項目結尾不加句號
- 連結獨立成行，前面加 `👉`，不要塞進句子裡
- 日期獨立成行，寫成 `活動期間｜2026/7/24－11/29`，不要塞進句子裡

---

## 8. 禁用清單

- ❌ 「小編」自稱
- ❌ 一行超過一個 emoji —— 疊放（🎉🎉🎉、😍😍）與不同 emoji 並置（🍁♨️、行首 🍁 配句尾 😍）都算、句尾隨手灑。**emoji 本身不禁用** —— 行首分類符與語氣 emoji 都可以用，一行一個，用法見第 4 節
- ❌ 驚嘆號連發（「超讚！！！」）。互動式鉤子可以用**一個**驚嘆號邀請留言
- ❌ 誇大詞：「史上最強」「絕對必買」「錯過再等一年（非事實時）」
- ❌ 網紅式空話：「真的太美了吧」「已哭」「衝就對了」
- ❌ 每行都加句號
- ❌ 未經查證的日期、票價、優惠金額

**最後一條最重要。** 素材裡沒有的日期、票價、優惠金額一律不准自己補。缺的話有兩種處理：

1. 用 `活動期間｜待確認` 標出來，讓同仁自己填
2. 整句拿掉，改寫成不需要數字的說法（「秋季限定」而非「2026/10/3－10/18」）

寧可少一個資訊，不要多一個錯誤 —— 粉專貼文一發出去就會被截圖轉傳。

---

## 9. 撰寫流程

1. 確認素材夠不夠（見〈動筆前〉）→ 不夠先問，一次問完
2. 確認貼文類型：景點推薦／節慶預告／行程開賣／知識懶人包／產品優惠
3. 蒐集事實：正式名稱、日期、地點、5 個以內亮點、連結
4. 選鉤子寫法（第 3 節）→ 寫轉場句（互動式跳過轉場）
5. 排主體：條列**預設 emoji 行首**，只有並列比較方案才換 `▌❶❷❸`（第 4 節）；有日期就補 `活動期間｜` 那行
6. 選 CTA（第 6 節）→ 補簽名行
7. 對照禁用清單（第 8 節）逐條檢查
8. 檢查行長：有超過 25 字的行就斷行
9. 逐行數 emoji：**每行超過一個就刪到剩一個**

## 最容易犯的六個錯

1. **用形容詞代替畫面** —— 「超級震撼」什麼都沒說，「火焰沿著繩索落下」才讓人想去
2. **該用 emoji 行首卻編號** —— 景點、亮點、體驗這種分類列舉不需要數字，編號留給「要讀者挑一個」的方案並列。前綴也不能混用：同一則裡 `❶` 跟 emoji 行首跟 `・` 一起出現版面立刻散掉，擇一用到底（`【】` `活動期間｜` `｜` `👉` 不在此限）
3. **促銷講三次** —— 開頭喊、中間喊、CTA 再喊，讀起來就是叫賣
4. **條列說明寫太長** —— 超過 25 字就不是條列，是段落，讀者會直接滑過去
5. **自己補日期票價** —— 素材沒有就標 `活動期間｜待確認`，發出去錯了是要發澄清文的
6. **該問的不問、不該問的猛問** —— 素材只有一句話就硬寫，或反過來連鉤子用哪種都要確認
